## 💡 What is portfoliAI?

Managing multi-asset portfolios across different brokers often leads to fragmented data, hidden fees, and skewed performance metrics. portfoliAI solves this by providing a developer-friendly, secure, and production-ready infrastructure that abstracts the complexity of quantitative finance reporting.

Our core engine ingests financial data, runs comprehensive data validation, and leverages fine-tuned Language Models to write sophisticated market narratives and portfolio health checks.

### Key Features
*   📊 **ROI Analysis Over Time:** Tracks consolidated historical returns, fully incorporating past sales, liquidations, and realized profits for an accurate lifetime equity curve.
*   🔍 **Granular Cost Breakdown:** Uncovers explicit platform commissions and statistically models implicit bid-ask spread costs based on high-precision intraday tracking.
*   🌡️ **Risk & Volatility Diagnostics:** Computes rolling volatility (e.g., 21-day windows), downside exposure, and benchmark tracking errors.
*   🌐 **Native Multi-Language Support:** Fully localized architecture (supporting English, Italian, and more) across all generated reports, email notifications, and UI components.

## 🛠️ The Tech Stack

We believe in building fast, deterministic, and highly scannable architectures. This organization houses the core sub-systems of the portfoliAI ecosystem:

*   **Backend Engineering:** Robust data processing and AI orchestration built with **Python**, **LangChain**, and **Pydantic** for strict schema enforcement and deterministic JSON outputs.
*   **AI Infrastructure:** Multi-provider architecture supporting high-throughput cloud models (e.g., Google Gemini Flash) and enterprise self-hosted setups via **Ollama** (Llama 3.3).
*   **Frontend & UI:** High-performance, reactive edge dashboards deployed on **Vercel** using **TypeScript**.
*   **Localization:** Industrial-grade internationalization workflow managed via **Babel (Gettext)**, ensuring compiled, bulletproof `.mo` catalogs for backend and email templates.

## 🔒 Security & Data Privacy First

Financial data requires absolute discretion. We bake privacy directly into our development lifecycle:
*   **Isolated Environments:** Clear boundary separation between user datasets, LLM prompts, and static codebases.
*   **Strict Anonymization:** Data payloads are programmatically stripped of personally identifiable information (PII) before interacting with any analytical engine.
*   **Deterministic Workflows:** We force open-source models to run on strict grammatical constraints (`temperature: 0.0`), neutralizing data hallucination risks entirely.
